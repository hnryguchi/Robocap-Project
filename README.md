# RoboCAP

**Português** · [English](README.en.md)

Registro da minha participação no RoboCAP, projeto de extensão universitária.

## Atuação no projeto

- Desenvolvimento de projetos com Arduino envolvendo LEDs e sensores.
- Criação de oficinas e minicursos de programação.
- Aplicação de lógica de programação em Python e C++.

## Conteúdo do repositório

| Arquivo | Descrição |
|---|---|
| [`arduino/led_blink.ino`](arduino/led_blink.ino) | Sketch Arduino que acende e apaga o LED embutido da placa (`LED_BUILTIN`) em intervalos de 1 segundo. |
| [`arduino/minicursos/exemplo_python.py`](arduino/minicursos/exemplo_python.py) | Exercício de lógica em Python: lê um número inteiro e informa se é par ou ímpar. |

## Como executar

- `led_blink.ino`: abra o arquivo na Arduino IDE, selecione a placa e a porta e faça o upload.
- `exemplo_python.py`: execute `python arduino/minicursos/exemplo_python.py` e digite um número inteiro.

## Tecnologias

Arduino, C++, Python, Git.

# RoboCAP

[Português](README.md) · **English**

Record of my participation in RoboCAP, a university outreach project.

## Role in the project

- Developed Arduino projects involving LEDs and sensors.
- Created programming workshops and mini-courses.
- Applied programming logic in Python and C++.

## Repository contents

| File | Description |
|---|---|
| [`arduino/led_blink.ino`](arduino/led_blink.ino) | Arduino sketch that turns the board's built-in LED (`LED_BUILTIN`) on and off at 1-second intervals. |
| [`arduino/minicursos/exemplo_python.py`](arduino/minicursos/exemplo_python.py) | Python logic exercise: reads an integer and reports whether it is even or odd (prompts and output are in Portuguese). |

## How to run

- `led_blink.ino`: open the file in the Arduino IDE, select the board and port, and upload.
- `exemplo_python.py`: run `python arduino/minicursos/exemplo_python.py` and enter an integer.

## Technologies

Arduino, C++, Python, Git.
